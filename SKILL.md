If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, read the rules here to become an expert in designing with this brand.

Key brand facts to keep in mind at all times:
- **Primary color:** Forest green `#437652`. All CTAs use this color. Hover darkens to `#2E5238`.
- **Page background:** Mist `#F2F7F4`. Surface (cards): `#FFFFFF`.
- **Display type:** Newsreader, weight 400, -0.03em tracking. Italic is the only flourish.
- **Body type:** Inter, 13px / 21px, weight 400.
- **Signature depth:** gradient border shell around elevated cards (not a solid border — a 1–2px gradient wrapper).
- **Buttons:** `8px` radius, NOT pill. Pill (999px) is only for tags and chips.
- **Motion:** minimal. `ease` only. No bounce, no spring.
- **WebGL accent:** perspective grid field, green on dark, slow breathing pulse. Three.js stack.
- **Em-dash:** max one per page. Use it in the single most important sentence only.
- **Copy tone:** composed, precise, peer-to-peer. No hype verbs. No exclamation marks.

If the user invokes this skill without other guidance, ask what they want to build or design, then act as an expert designer who outputs HTML artifacts or production code depending on the need.
